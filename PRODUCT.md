## Platform

web

## Stack

Static HTML5, CSS3, and vanilla JavaScript (zero-build architecture)

## Users

- **Primary**: Tech company recruiters, talent acquisition teams, and engineering leads looking for vocational high school (SMK) students for internship / Praktik Kerja Lapangan (PKL) placements or entry junior roles.
- **Secondary**: Local businesses, school organizations, or personal clients seeking freelance website development.

## Product Purpose

Serve as a credible, interactive personal portfolio website for Aldentra Supranatantra that proves practical programming competency in web and game development, demonstrates continuous learning, and directly facilitates internship opportunities and project inquiries.

## Positioning

A passionate SMK PPLG student developer who builds functional, interactive web applications (such as personal finance and productivity platforms) and games with clean code, modern UX sensibilities, and hands-on technical competence rather than just theoretical school projects.

## Operating Context

- Evaluated by recruiters during internship vetting cycles, viewing via both desktop and mobile devices.
- Direct contact pathways through email (`supranatantra10@gmail.com`), GitHub, and social channels.
- Multi-page static architecture allowing direct navigation across Home, About, Projects, Skills, and Contact.

## Capabilities and Constraints

- **Capabilities**: Project showcase with interactive category filtering (Web, Game, Backend), responsive mobile navigation, interactive contact form, animated UI elements and counters, detailed project breakdown with tech stack tags.
- **Constraints**: Vanilla client-side static stack (no server-side rendering or heavy JS frameworks), fast asset delivery, zero-build deployment.
- **Undecided**: Potential migration to static site generators (e.g. Astro) or backend integration for form submissions if future scale requires.

## Product Principles

1. **Proof Over Claims**: Let real project demonstrations, features, and source code prove ability rather than marketing buzzwords.
2. **Accessible & Responsive Baseline**: Flawless experience across desktop and mobile with accessible contrast and smooth interaction.
3. **Clarity of Purpose**: Ensure recruiters can immediately understand who Aldentra is, what he builds, and how to reach out for internship opportunities.
4. **Honest Representation**: Accurate presentation of skills, current learning trajectory, and project status.

## Accessibility & Inclusion

- Adherence to WCAG AA contrast standards across dark surfaces and text.
- Fully accessible keyboard navigation and proper mobile touch targets (min 44px).
- Semantic HTML landmarks across all portfolio pages.
